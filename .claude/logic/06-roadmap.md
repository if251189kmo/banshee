Немає: на 2026-10-03 власник відповів на всі. Нові питання записуємо сюди одразу, щойно вони з'являються.

## Дії власника

- **Ключ Claude** отримано 2026-10-03. Ввести командою `npm run key` після кроку П3 плану, перед етапом 0 ([12-api.md](12-api.md)). Змінна середовища не потрібна; якщо `BANSHEE_ANTHROPIC_API_KEY` уже задано — видалити. Кредити API купуються в Console (крок 2 у [12-api.md](12-api.md)); без них Banshee працює в базовому режимі.
- **Azure** — не потрібен: голос локальний (рішення власника 2026-10-03).
- **`.mcp.json`** лишається (рішення власника 2026-10-03), але лише з серверами Banshee: context7 (документація) і chrome-devtools (перевірка презентації й інтерфейсу). figma, mui, atlassian і gitlab — від payments, прибрати; токен GitLab відкликати. Новий вміст файлу, без секретів:

  ```json
  {
    "mcpServers": {
      "context7": {
        "type": "stdio",
        "command": "npx",
        "args": ["-y", "@upstash/context7-mcp"]
      },
      "chrome-devtools": {
        "type": "stdio",
        "command": "npx",
        "args": ["-y", "chrome-devtools-mcp@latest"]
      }
    }
  }
  ```
  - Файл лишається в `.gitignore`: якщо туди колись знову допишуть токен, у git він не потрапить.
  - Claude файл не читає й не змінює (deny і хук `guard-secrets`); редагує власник.
- **Плагін `typescript-lsp`** — встановити: `/plugin install typescript-lsp@claude-plugins-official` у Claude Code і `npm i -g typescript-language-server typescript`. У налаштуваннях він увімкнений, але не встановлений.
- ~~Увімкнути ESU на цьому ПК~~ — зроблено 2026-10-03, безкоштовно, до 12.10.2027 ([11-sync.md](11-sync.md)).
