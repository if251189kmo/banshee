# 12 · Підключення API Claude

Покрокова інструкція для власника: як оплатити API Claude і підключити до нього Banshee. Займає ~10 хвилин; потрібні email і банківська картка. Нижче — як ввести ключ, поки вікна налаштувань ще немає.

Підписка Claude API не покриває. Banshee — власний застосунок, тож працює лише з API-ключем і передплаченими кредитами ([03-brain.md](03-brain.md), «Як платити»). Без ключа Banshee теж працює — у базовому режимі, без ШІ.

## Кроки

| # | Що зробити | Де |
|---|---|---|
| 1 | Увійти або створити акаунт. Можна тим самим email, що й у Claude, але оплата API окрема від підписки | [platform.claude.com](https://platform.claude.com/) |
| 2 | **Buy credits** → $10 (мінімум $5). Кредити діють рік від покупки й не повертаються; до суми може додатися податок | [Settings → Billing](https://platform.claude.com/settings/billing) |
| 3 | **Auto-reload** → вимкнути. Тоді залишок кредитів — жорстка стеля витрат | там само |
| 4 | **Spend limits** → **Set limit** → $20 на місяць. Запасна стеля на боці Anthropic, якщо Banshee через помилку не зупиниться сам | там само |
| 5 | **Create key**: назва `Banshee-<ПК>`, **Linked account** — ти. Ключ `sk-ant-…` показується лише раз, тож скопіюй його одразу | [Settings → API keys](https://platform.claude.com/settings/keys) |
| 6 | Banshee → Центр керування → Налаштування → Мозок і витрати → **Ключ API Claude** → вставити → **Перевірити** | Banshee |
| 7 | Скажи «Banshee, розкажи щось цікаве про космос» — відповідь дасть ШІ. За кілька хвилин запит з'явиться в Console | [Usage](https://platform.claude.com/usage) |

Джерела, перевірено 2026-10-03: [Get your API key](https://platform.claude.com/docs/en/get-api-key) · [Setting your own spend limit](https://platform.claude.com/docs/en/api/rate-limits#setting-your-own-spend-limit) · [How do I pay for my Claude API usage](https://support.claude.com/en/articles/8977456).

## Ключ до появи вікна налаштувань (етапи 0–1)
Ключі вводяться лише в налаштуваннях Banshee — рішення власника 2026-10-03. Змінних середовища для ключів немає.

Вікно налаштувань з'явиться на кроці 1.7 плану ([13-plan.md](13-plan.md)), а ключ потрібен уже на етапі 0. До того крок 6 виконує команда проєкту `npm run key`, вона з'явиться на кроці П3:
- питає ключ Claude: вставити Ctrl+V або правою кнопкою миші, замість символів — «•». Ctrl+V, який термінал не перехопив, бере ключ прямо з буфера обміну;
- `npm run key -- --clipboard` — без вставки: скопіюй ключ у Console й запусти команду; ключ береться з буфера обміну, а після збереження буфер очищується (журнал Win+V — вручну);
- пише в той самий запис Credential Manager, що й вікно налаштувань, тож на кроці 1.7 ключ уже на місці;
- одразу перевіряє ключ запитом `GET /v1/models`; показує лише результат і останні 4 символи;
- запускає власник у своєму терміналі: VS Code або PowerShell. Claude Code цю команду не запускає — ключ вводить лише власник, а хук `guard-secrets` її блокує.

Ще п'ять правил:
- **Змінна `BANSHEE_ANTHROPIC_API_KEY` більше не потрібна.** Якщо її вже задано за попередньою інструкцією — видалити в PowerShell:

  ```powershell
  [Environment]::SetEnvironmentVariable('BANSHEE_ANTHROPIC_API_KEY', $null, 'User')
  ```
- **Не `ANTHROPIC_API_KEY`.** Цю змінну читає й Claude Code. Якщо вона задана, Claude Code переходить з підписки на оплату за API, а в режимі `-p` — навіть без питання ([Claude Code: Authentication](https://code.claude.com/docs/en/iam)).
- **Перевірка** — `npm run check:api`: список моделей і один короткий виклик Haiku. Ключ не друкується. Якщо кредитів немає (крок 2), виклик Haiku поверне помилку оплати.
- **Ключ у чат не вставляти.** Він потрапив би в транскрипт.
- **Ключ не передавати аргументом** (`npm run key sk-ant-…`): рядок команди лишається в історії PowerShell, у файлі `(Get-PSReadLineOption).HistorySavePath`. `npm run key` такий виклик відхиляє. Якщо ключ туди вже потрапив — відкликати його в Console, створити новий, видалити рядок з історії.

## Голос — без Azure
Azure Speech не використовуємо (рішення власника 2026-10-03): обліковий запис Azure без даних картки не активується, а вводити картку власник не хоче. Голос працює на локальних моделях — Parakeet і Piper — і не потребує ні облікового запису, ні ключа ([02-voice.md](02-voice.md)). Покрокова інструкція Azure лишилася в історії версії 3.5.

## Ключ
- **Де вводиться** — лише в Banshee: майстер першого запуску або Налаштування → Мозок і витрати (рішення власника 2026-10-03). Змінних середовища Banshee не читає.
- **Де зберігається** — у Windows Credential Manager, запис `claude-api-key.Banshee` (служба `Banshee`, обліковий запис `claude-api-key`): Панель керування → Диспетчер облікових даних → Облікові дані Windows → Загальні облікові дані. До 2026-10-04 запис називався `Banshee/claude-api-key` і через помилку бібліотеки не читався; наступне збереження ключа його видаляє. У пам'ять, журнал, промпт, файл `.banshee` і синхронізацію ключ не потрапляє.
- **Перевірка** — запит до списку моделей (`GET /v1/models`): безкоштовно, без токенів.
- **Окремий ключ на кожен ПК.** Якщо ПК загубиться, досить відкликати лише його ключ у Settings → API keys.
- **Строк дії** задається під час створення. Коли ключ спливе, Banshee перейде в базовий режим і скаже «Ключ API недійсний».

## Поповнення
- $10 вистачає приблизно на місяць звичайного користування: ≈ $11 при 50 командах на день ([03-brain.md](03-brain.md)).
- Banshee не бачить баланс у Console. Після поповнення введи суму в налаштуваннях: Banshee відніматиме з неї свої витрати й попередить, коли за його оцінкою лишиться менше за $2. Точний залишок — у Settings → Billing.
- Автопоповнення можна ввімкнути пізніше, але лише разом з лімітом у Console (крок 4).

## Що бачиш і що робити

| Стан ШІ | Чому | Що робити |
|---|---|---|
| ✅ ШІ активний | ключ перевірено, ліміти не вичерпано | — |
| ⏸ Базовий режим: вимкнено | ШІ вимкнено вручну | увімкнути в треї, налаштуваннях або голосом |
| ⏸ Базовий режим: немає ключа | ключ ще не додано | кроки 1–6 |
| ⏳ Ліміт дня | витрати за день досягли $1 | чекати до 00:00 або дозволити «ще $1 на сьогодні» кліком |
| ⏳ Ліміт місяця | витрати за місяць досягли $20 | чекати до 1-го числа або підняти ліміт вручну |
| 📡 Немає зв'язку | немає мережі або API не відповідає | нічого: Banshee перевіряє щохвилини й повертається сам |
| ⛔ Ключ недійсний | ключ відкликано, він сплив або не має доступу | новий ключ, кроки 5–6 |
| 💳 Оплата | скінчилися кредити або проблема з карткою | поповнити, крок 2 |
| 💳 Ліміт Console | досягнуто ліміту з кроку 4 | чекати дату з повідомлення або підняти ліміт у Console |

Як Banshee визначає ці стани за відповідями API — [03-brain.md](03-brain.md), «Стан ШІ й базовий режим».

## Базовий режим
- **Працює:** слово «Banshee» і голос, рутини (вбудовані, власника, вивчені), «стоп» і «скасуй», пам'ять, налаштування, журнал, «Активність», синхронізація й експорт.
- **Не працює:** довільні запити й розмова, нові задачі, ескалація, рефлексія й нічний самоаналіз.
- **Вимкнути ШІ:** меню трею → «ШІ: увімкнено», Налаштування → Мозок і витрати → «Використовувати ШІ», або голосом «Banshee, базовий режим».
- **Увімкнути:** там само або голосом «Banshee, увімкни ШІ» — з підтвердженням, бо це коштує грошей.
