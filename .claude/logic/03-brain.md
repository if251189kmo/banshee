## Маршрутизація

- **Рутина.** Нормалізований текст збігся з рутиною впевнено — виконуємо локально, без LLM. Як саме розпізнається збіг — [04-memory.md](04-memory.md).
- **ШІ вимкнено або недоступний** — базовий режим: команда без рутини не виконується, Banshee каже чому (див. «Стан ШІ й базовий режим»).
- **Проста дія.** Інструменти з позначкою `final` (гучність, відкрити програму, музика): якщо дія вдалася, хід завершується без другого виклику. Фразу вже озвучено, решту core договорює шаблоном «Готово». Якщо дія не вдалася, результат іде в Haiku.
  - Тому незалежні дії однієї команди («відкрий ютуб і зроби гучність сорок») модель викликає разом, в одній відповіді: інакше хід завершиться після першої. Це правило є в системному промпті; виконання перевіряє крок 0.1 ([13-plan.md](13-plan.md), «Ризики плану»).
- **Кілька кроків.** Звичайний агентний цикл: `tool_result` → Haiku → наступна дія.
- **`escalate(task, reason)`.** Haiku викликає його, коли:
  - потрібен план із понад ~5 кроків або порівняння варіантів;
  - треба розібрати довгий текст чи документ;
  - та сама задача двічі не вдалася;
  - власник просить «подумай краще».

  Sonnet працює окремим субагентом зі своїм контекстом і кешем і повертає результат як `tool_result`. Озвучує результат Haiku.
- **`code_task(project, task)`.** Banshee відкриває Claude Code у терміналі в теці проєкту з налаштувань і передає задачу першим повідомленням. Далі працюєш ти, за своєю підпискою Claude: $0 понад неї. Автономний режим через Agent SDK працював би лише з API-ключем і коштував би окремо за кожну задачу ([05-safety.md](05-safety.md)).
  - Запуск: `claude "<задача>"` у новому вікні PowerShell. Windows Terminal (`wt.exe`) — якщо встановлений; на ПК власника його немає.
  - Оточення дочірнього процесу — без `ANTHROPIC_API_KEY` і `ANTHROPIC_AUTH_TOKEN`, щоб Claude Code працював за підпискою.
  - CLI `claude` на ПК власника вже є в PATH (перевірено 2026-10-03).

## Реалізація — крок 1.5 (2026-10-05)

`apps/core/src/engine.ts` (рушій ходів), `brain/loop.ts` (цикл Haiku), `brain/model-client.ts` (клієнт моделей), `pc-client.ts` (інструменти ПК через MCP). Системний промпт, рядок контексту ходу, ціни й класифікація помилок переїхали з `scripts/lib` у `apps/core/src/brain` без змін — хеші промпта й схем ті самі, тож точність і кеш кроку 0.1 чинні.
- **Хід:** чужий голос відкидається до маршрутизації (лічильник `voice_rejected`); керування («стоп», «скасуй», «нова розмова») — одразу; рутина — локально; решта — цикл Haiku або відповідь базового режиму. Кожен хід — рядок `turns`, кожна дія — `actions`, кожен виклик — `llm_calls` з вартістю за цінами з налаштування «Моделі й ціни».
- **Цикл Haiku:** до 6 запитів на команду. Фраза перед дією озвучується, як тільки прийшла. Кожен виклик інструмента — оцінка рівня в `mcp/pc`, підтвердження за рівнем, виконання, запис у журнал. Ліміти перевіряються перед кожним запитом, не лише на початку ходу.
- **Хід не вдався** (час, відмова, обрізана відповідь, виклик текстом, «стоп»): історія розмови повертається до стану перед ходом — інакше наступний запит мав би `tool_use` без `tool_result` і API повернув би помилку. Власник чує коротку причину.
- **Історія в запиті** — останні 40 повідомлень розмови; стискання старших ходів у підсумок — етап 3.
- **Профіль власника** до етапу 3 — заглушка «No confirmed facts yet»: блок з точкою кешу не може бути порожнім.
- **Ескалація:** Sonnet 5.5 отримує лише текст задачі й короткий системний промпт «відповідай українською, стисло, без markdown». Відповідь повертається Haiku як `tool_result`; відмова Sonnet — теж `tool_result` з помилкою.
- **`eager_input_streaming` не вмикаємо:** аргументи інструментів Banshee — десятки байтів, а зміна визначень змінила б кешований префікс і вимагала б нового прогону еталонного набору.
- **Після простої дії** core говорить «Готово», а дані `system_info` — вільне місце, мережу, заряд, час і дату — словами за шаблоном: моделі вже не викликаємо, а без цього власник відповіді не почув би (крок 1.8).
- **Шляхи від моделі:** якщо модель написала шлях з одним «\», JSON перетворює «\t», «\n» на керівні символи; core повертає їх у полях шляхів до виконання (крок 1.8).
- **Збої API** за класами SDK: ключ (401, 403) → «ключ», оплата → «оплата», ліміт Console і стеля тарифу → «ліміт Console», 429, 5xx і немає мережі → «немає зв'язку» з новою спробою через хвилину.
- Тести — на підробній моделі й інструментах: рутина, базовий режим, проста дія, 🟡 і 🔴, «скасуй», ескалація, ключ, ліміт, «стоп». Наживо через API — разом із демонстрацією власнику: запит коштує кредитів, а інструменти діють на ПК.

## Один хід за раз
- Нова команда під час ходу, поки дія ще не почалася: попередній хід скасовується, виконується нова.
- Нова команда під час дії: чекає її завершення, до 30 с, і виконується після неї. Banshee каже: «Секунду, закінчую попереднє».
- «Стоп» діє завжди й одразу.
- Фонові задачі — рефлексія, самоаналіз, синхронізація — ходам не заважають: вони мають нижчий пріоритет і окремі виклики.

## Системний промпт
Англійською, бо так менше токенів. Частини в порядку кешування:
1. **Роль.** Голосовий асистент власника на Windows; відповідає українською, коротко; першу фразу дає перед дією.
2. **Політика.** Рівні дій, чужий вміст, заборона вигадувати результати інструментів, коли кликати `escalate`.
3. **Інструменти** зі схемами ([01-architecture.md](01-architecture.md), «Інструменти етапу 1»).
4. **Профіль власника й правила** — ≤ 1,5K токенів, оновлюються раз на добу.

Частини 1–2 і правила інструментів з прикладами — `scripts/lib/system-prompt.ts` (крок 0.1). Приклади в промпті не повторюють команд еталонного набору, інакше точність була б завищена. Префікс разом з інструментами — 6288 токенів (крок 0.1), більше за поріг кешу 4096; число друкує `npm run evals`.

Поле `system` — два блоки: незмінний промпт і профіль. Точка кешу з TTL 1 год — на профілі, вона кешує інструменти, промпт і профіль разом. Друга точка — автоматична (`cache_control` верхнього рівня запиту), на кінці розмови, TTL 5 хв.

**Рядок контексту ходу** — перший рядок кожного ходу власника: `[2026-10-05 10:30 Monday · voice]`, далі команда. Дата, час, день тижня англійською (менше токенів) і джерело — `voice` або `text`. Модель рахує від нього «вчора», «за тиждень».

**Швидкий шлях Haiku:** `max_tokens` 1024, без thinking, `tool_choice` типовий (`auto`), паралельні виклики дозволені, інструменти без `strict`.

**Виміряно на кроці 0.1** (2026-10-04, [evals/stage0-report.md](../../evals/stage0-report.md)): точність 98 %, кеш 94 %, 0,15 ¢ за виклик і 0,21 ¢ за команду — менше за оцінку 0,28 ¢, бо історія розмови в наборі коротка. Перший токен — p50 0,61 с, p90 0,82 с.

Після кешованого префікса — нові факти за день (змінюються рідко), далі історія розмови. Дата й час — у тексті кожного нового ходу власника: усе, що змінюється щоходу, має стояти після останньої точки кешу, інакше кеш історії не спрацює.

## Контекст розмови

- Розмова триває, поки паузи коротші за 10 хв, або до команди «нова розмова».
- Дві точки кешу:
  1. інструменти, системний промпт і профіль — TTL 1 год;
  2. кінець історії розмови — TTL 5 хв.

  Точка з довшим TTL іде першою.
- Історія довша за ~20K токенів: старші ходи стискаються в підсумок.
- Після простої дії без другого виклику наступний запит починається з `tool_result` тієї дії, а вже за ним іде новий текст власника. Інакше API поверне помилку.

## Haiku 4.5: перевірено за документацією (2026-10-03)

- Контекст 200K, вихід до 64K.
- Працюють tool use, prompt caching, tool search, Batch API (−50%).
- Thinking у швидкому шляху не вмикаємо: у Haiku 4.5 лише мислення з `budget_tokens`, а затримка важливіша.
- Computer use Haiku 4.5 підтримує (`computer_20250124`), але це скриншоти й координати: кожен крок — зображення на ~1,5K токенів і окремий виклик моделі. Тому інтерфейсами керуємо через UI Automation: дерево елементів за назвами швидше, дешевше й надійніше.
- Кеш вмикається від 4096 токенів незмінного префікса. Читання кешу — $0.10 за 1M; запис — 1.25× (TTL 5 хв) або 2× (TTL 1 год).

## Як платити

- **Підписка Claude API не покриває.** Власні застосунки на кшталт Banshee працюють лише з API-ключем: вхід через підписку Anthropic дозволяє тільки в Claude Code і своїх застосунках ([Legal and compliance](https://code.claude.com/docs/en/legal-and-compliance)).
- API оплачується окремо в Claude Console передплаченими кредитами: мінімум $5, діють рік, не повертаються.
- **Старт:** $10 без автопоповнення й ліміт $20 на місяць у Console. Баланс тоді — жорстка стеля: на нулі API зупиняється, а Banshee переходить у базовий режим.
- Далі — поповнювати ~$10–15 на місяць, коли Banshee попередить.
- Покроково з посиланнями — [12-api.md](12-api.md).

## Ліміти витрат

Рішення власника (2026-10-03): **$1 на день і $20 на місяць**.

- Core рахує вартість кожного виклику з `usage` і таблиці цін і пише її в `llm_calls` ([04-memory.md](04-memory.md)).
- **80 % ліміту** — попередження в треї. Крок 1.7: core після кожного виклику Claude порівнює витрати з лімітами й надсилає сповіщення Windows — раз на день для денного ліміту й раз на місяць для місячного.
- **Денний ліміт.** На $1 Banshee переходить у базовий режим до 00:00; дозволити «ще $1 на сьогодні» можна лише кліком. Звичайне навантаження — ≈ $0,37 на день, тож ліміт ловить помилку, через яку модель ходить по колу.
- **Місячний ліміт.** На $20 — базовий режим до 1-го числа. Підняти ліміт — лише вручну в налаштуваннях.
- **Для всіх ПК разом:** кожен ПК бачить витрати інших через синхронізовану статистику `usage_daily`, із затримкою до 10 хв ([11-sync.md](11-sync.md)).
- **Остання стеля — на боці Anthropic:** залишок кредитів без автопоповнення й ліміт $20 у Console ([12-api.md](12-api.md), кроки 3–4).

## Стан ШІ й базовий режим

ШІ — це виклики Claude API. Без них Banshee працює в **базовому режимі**: виконує рутини й команди, яким не потрібна модель. Вимога F11.

| Стан | Причина | Як повертається ШІ |
|---|---|---|
| ШІ активний | ключ перевірено, ліміти не вичерпано | — |
| Базовий: вимкнено | власник вимкнув ШІ | власник вмикає |
| Базовий: немає ключа | ключ ще не додано | ключ додано й перевірено |
| Базовий: ліміт дня | витрати за день досягли $1 | о 00:00 або «ще $1 на сьогодні» кліком |
| Базовий: ліміт місяця | витрати за місяць досягли $20 | 1-го числа або ліміт піднято вручну |
| Базовий: немає зв'язку | немає мережі, 5xx чи 529 після повторів | сам: перевірка щохвилини |
| Базовий: ключ | 401 `authentication_error` або 403 `permission_error` | новий ключ |
| Базовий: оплата | 402 `billing_error` або 400 про нестачу кредитів | поповнення кредитів |
| Базовий: ліміт Console | 400, повідомлення починається з «You have reached your specified» | дата з повідомлення або ліміт піднято в Console |

- **Що працює:** слово «Banshee» і голос (локальні моделі — це не Claude), рутини вбудовані, власника й вивчені, «стоп» і «скасуй», пам'ять, налаштування, журнал, «Активність», синхронізація й експорт.
- **Що ні:** довільні запити й розмова, нові задачі, ескалація, рефлексія. Нічний самоаналіз переноситься на першу ніч з увімкненим ШІ.
- **Вбудовані команди** — рутини, що постачаються з Banshee (`origin = builtin`): гучність, медіа, відкрити програму, теку чи сайт зі словника, вікна, час і дата. Тож базовий режим корисний з першого дня.
- **Відповідь** на команду, якій потрібен ШІ, — коротко й з причиною: «Без ШІ це не вмію. Увімкнути?», «Ліміт на сьогодні вичерпано. Дозволити ще $1?», «Скінчилися кредити API». В оверлеї — кнопка дії. Команди в чергу не ставляться. У журналі ходів — `route = none`, `outcome = no_ai`.
- **Перемикач:** меню трею, Налаштування → Мозок і витрати, голосом «Banshee, базовий режим» / «Banshee, увімкни ШІ». Вимкнення — одразу; увімкнення голосом — 🟡 дія з підтвердженням, бо коштує грошей. Перемикач — налаштування пристрою. Кожне перемикання пишеться в журнал із причиною.
- **Стан видно завжди:** позначка на значку трею й в оверлеї, картка «Стан ШІ» на «Огляді» й у налаштуваннях ([09-ui.md](09-ui.md), [10-settings.md](10-settings.md)).
- **Перевірка ключа і зв'язку** — запит до списку моделей (`GET /v1/models`): безкоштовно, без токенів.
- **Реалізація — крок 1.6** (`apps/core/src/basic`, `ai/state.ts`, 2026-10-05):
  - 24 вбудовані рутини: гучність (рівень, повна, половина, тихіше, голосніше, вимкнути й увімкнути звук), медіа, вікна, відкрити програму, сайт чи теку зі словника, закрити програму (🟡), блокування, час, дата, перемикач ШІ. Вбудований словник — ≈ 20 програм, 6 сайтів і стандартні теки з відмінками й суржиком; назви власника мають перевагу.
  - Стан ШІ рахується в такому порядку: вимкнено → немає ключа → ключ, оплата чи ліміт Console → ліміт місяця → ліміт дня (з урахуванням «ще $1») → немає зв'язку → активний. Попередження з 80 %: спершу місячного ліміту, бо його не скинути кліком.
  - Перемикач ШІ голосом — вбудовані рутини «базовий режим» / «увімкни ШІ»; зміна пишеться в `settings` і журнал дій з попереднім значенням.
  - Еталонний набір без ШІ: 21 з 50 команд виконується вбудованими рутинами — усі з правильними діями; уточнення, відмови й складні команди рутиною не стають. У базовому режимі — 0 запитів до API на всіх 50 командах у кожному зі станів.

## Збої API

- 429, 5xx і 529 (overloaded): повторює сам SDK — 2 спроби з експоненційною паузою, з урахуванням `retry-after` (типове `maxRetries: 2`). Власних повторів поверх SDK немає. Далі — базовий режим «немає зв'язку».
- 401, 402, 403 і 400 про ліміт чи кредити не повторюються — це не тимчасові помилки. Одразу базовий режим із причиною, таблиця вище.
- 429 без заголовка `retry-after` і з `error.details.error_code = enforced_spend_limit_reached` — вичерпано місячну стелю тарифу Anthropic; повтори не допоможуть ([Rate limits](https://platform.claude.com/docs/en/api/rate-limits), перевірено 2026-10-03).
- Помилки класифікуємо за типізованими класами SDK і полем `type` (`authentication_error`, `billing_error`, `rate_limit_error`…), а не за текстом. Виняток — ліміт Console: його 400 відрізняємо від інших за початком повідомлення.
- Перший токен не прийшов за 8 с: запит скасовується, Banshee каже про це.
- Команда «стоп» скасовує запит через `AbortController`.

## Пастки API

- Тільки точні ID без дат; виклики лише через `@anthropic-ai/sdk`, не сирим `fetch`.
- **ID моделей і таблиця цін** — у конфігурації core, а не в коді. Якщо Anthropic виведе модель з обігу, нову задаємо прихованим налаштуванням «Мозок → Моделі» без нової версії Banshee.
- **Ключ API — не `ANTHROPIC_API_KEY`.** SDK отримує ключ явно: `new Anthropic({ apiKey })`. Ключ береться лише з Credential Manager, куди його вводять у налаштуваннях Banshee; змінних середовища Banshee не читає. Змінна `ANTHROPIC_API_KEY` перевела б Claude Code власника з підписки на оплату за API ([Claude Code: Authentication](https://code.claude.com/docs/en/iam)).
- **`strict: true` на інструментах** — перший запит після зміни схем чекає ≈ 22 с (API компілює граматику й тримає її 24 год), кожен наступний — ≈ +0,35 с до першого токена (крок 0.1). Тому без strict; аргументи перевіряє код.
- **Виклик текстом.** Модель може написати виклик у тексті («media {"action": "previous"}») замість справжнього — так було на кроці 0.1, доки приклади в промпті мали схожий формат. Core не озвучує текст з назвою інструмента й аргументами і вважає такий хід збоєм.
- Префікс коротший за 4096 токенів кеш не вмикає, і помилки при цьому немає. Тому слідкуємо за `usage.cache_read_input_tokens` / `cache_creation_input_tokens` у `llm_calls`.
- Дата й час — лише в повідомленні ходу, після останньої точки кешу; нові факти — блоком після префікса. Профіль ≤ 1,5K токенів, оновлюється раз на добу.
- Зміна моделі посеред розмови скидає кеш → ескалація йде окремим субагентом.
- Понад 10–30 інструментів — tool search: 3–5 найчастіших без `defer_loading`, решта з `defer_loading: true`.
- Sonnet 5.5: `thinking: {type: "disabled"}` і примусовий `tool_choice` (`any` / `tool`) повертають 400. Найнижчий рівень мислення — `thinking: {type: "between_tools"}`, лише з effort `high` і нижче ([API errors](https://platform.claude.com/docs/en/api/errors), перевірено 2026-10-03).
- **Ескалація на Sonnet 5.5:** `thinking: {type: "adaptive"}` і `output_config.effort: "medium"`. Типове `high` дорожче; рівень уточнюємо на етапі 1 за еталонним набором.
- **Відмова Sonnet 5.5** — HTTP 200 зі `stop_reason: "refusal"`, тож `stop_reason` перевіряємо до `content`. PowerShell-задачі можуть дати хибну відмову категорії `cyber`. Резервна модель на відмову — `fallbacks: "default"` (beta `server-side-fallback-2026-07-01`), за рекомендацією Anthropic; її вартість іде в `llm_calls`, ліміти $1 / $20 діють. Якщо відповіді немає й так — Banshee каже, що модель відмовилась, без повторів.
- **Історію субагента Sonnet лише дописуємо.** Блоки мислення прив'язані до розмови: зміна попередніх повідомлень, системного промпту чи інструментів дає 400 для акаунтів, створених з 31.08.2026. Дописуємо незалежно від дати акаунта.
- Memory tool з API у швидкому шляху не використовуємо: API додає інструкцію «спершу переглянь пам'ять», а це +1 запит.
- Підписка Claude API не покриває — див. «Як платити».
- Перед кодом, що викликає Claude API, — скіл `claude-api`.
