- 1.2–1.6 закрито 2026-10-05: `packages/shared`, БД і журнал роботи, інструменти ПК, агентний цикл, базовий режим без ШІ; етап 1 іде паралельно з етапом 0 за вказівкою власника. 1.8 закрито: еталонний набір на рушії core — 96 %, 0 ін'єкцій. 0.8 закрито: нативні модулі працюють в Electron 44.5.1, N6 тримається. 1.1 закрито: каркас Electron — трей, core в `utilityProcess` з перезапуском за 0,65 с. 1.7 закрито: оверлей, картки підтвердження, гарячі клавіші, центр керування, майстер, ключ у налаштуваннях. 1.10 закрито: довідка й «Про програму». 1.9 не закрито: встановлювач зібрано й перевірено на цьому ПК, чекає встановлення власником і ВМ Windows 11; 0.7 чекає мікрофона власника;
- 0.5 не закрито: рішення власника 2026-10-05 — власна модель слова з перевіркою голосу, далі довчання; пропуски 17 % при цілі 5 %, ітерація 5 — важкі обчислення.

## Правила для кожного кроку
- `npm run check` = typecheck, lint, тести. Зміна промпта, інструментів чи моделі — ще `npm run evals`.
- ТЗ і презентація оновлюються в тій самій зміні; рішення — у таблицю [README.md](README.md) з датою.
- З кроку 1.10 зміна, що додає чи змінює функцію для користувача, оновлює її тему в довідці програми ([09-ui.md](09-ui.md)).
- Коміт у локальний git — після перевірок, з дозволу власника.
