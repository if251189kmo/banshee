## Правила для кожного кроку
- `npm run check` = typecheck, lint, тести. Зміна промпта, інструментів чи моделі — ще `npm run evals`.
- ТЗ і презентація оновлюються в тій самій зміні; рішення — у таблицю [README.md](README.md) з датою.
- Коміт у локальний git — після перевірок, з дозволу власника.

## Ризики плану

| Ризик | Ознака | Що робимо |
|---|---|---|
| «Banshee» з українською вимовою погано ловить KWS | пропуски > 5 % на кроці 0.5 | інші варіанти написання ключового слова; власна модель openWakeWord |
| Немає готових збірок нативних модулів | помилка встановлення на кроці 0.8 | версія Electron, для якої збірки є; інакше — Build Tools після звільнення місця на C: |
| Whisper на GTX 960 повільний | розпізнавання фрази > 0,8 с на кроці 0.3 | спекулятивний старт; менша модель; хмарний Whisper Groq без картки — лише за рішенням власника ([02-voice.md](02-voice.md)) |
| Whisper у пам'яті не вкладається в N6 | RAM > 500 МБ у спокої на кроці 0.8 | модель у пам'яті відеокарти; інакше — переглянути N6 з власником |
| Мало місця на C: (5,8 ГБ) | помилки запису | дані розробки й моделі — на D: |
| Defender блокує непідписану програму | карантин, попередження | виняток для теки програми |
| Скінчилися кредити API | 402 або 400 від API | базовий режим; поповнення ([12-api.md](12-api.md)) |
