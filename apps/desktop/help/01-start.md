# Як почати

Banshee живе в треї — значок біля годинника. Клік по ньому відкриває центр керування.

- **Майстер першого запуску** показує ключ Claude і гарячі клавіші. Його можна пройти знову будь-коли.
- **Ключ Claude** потрібен для довільних прохань. Його створюють у Console Anthropic, а вставляють у Banshee — він зберігається в Windows Credential Manager.
- **Без ключа** працює базовий режим: гучність, медіа, програми, вікна, час — без запитів до API.
- **Оверлей** — Ctrl+Shift+B: напиши команду й натисни Enter.
