# Як кликати Banshee

- **Оверлей** — Ctrl+Shift+B. Поле команди з'являється вгорі екрана, де курсор. Enter — виконати, Esc — сховати. Сам ховається через 8 с без дій.
- **«Стоп»** — Ctrl+Shift+X або команда «стоп»: скасовує запит до ШІ, дію й підтвердження.
- **Голосом**, коли «Голосові команди» ввімкнено: «Banshee, відкрий телеграм» або кнопка 🎙 в оверлеї — без слова. **Вікно продовження** — 5 с після відповіді Banshee слухає без слова.
- Гарячі клавіші змінюються в налаштуваннях; якщо поєднання зайняте іншою програмою, Banshee про це скаже.
