# Приватність

**Лишається на цьому ПК:** пам'ять, журнал дій, налаштування, журнали роботи — у теці Banshee. Голос, коли з'явиться, теж розпізнається тут: аудіо нікуди не йде.

**Іде в Claude:** текст команди, коли потрібен ШІ, і результати дій для відповіді. У базовому режимі — нічого.

**Ключ Claude** — у Windows Credential Manager. Banshee показує лише «••••1234»; у журнал, пам'ять і діагностику ключ не потрапляє.

Чужий вміст — сайти, листи, файли — у пам'ять не записується.

**Видалити все** — «Про програму» → «Видалити всі дані»: тека Banshee — у Кошик, ключ — з Credential Manager, програма — з ПК.
