# Гарячі клавіші

| Дія | Клавіші |
|---|---|
| Оверлей | Ctrl+Shift+B |
| Стоп | Ctrl+Shift+X |
| Пауза мікрофона — коли голос увімкнено | Ctrl+Shift+M |
| Підтвердити 🟡 | Enter у картці |
| Підтвердити 🔴 | Ctrl+Enter у картці |
| Відмовитись | Esc у картці |
| Довідка до розділу | F1 у центрі керування |

Поки Banshee працює, його поєднання не доходять до інших програм — наприклад, Ctrl+Shift+B у VS Code. Змінити їх можна в налаштуваннях.

[Відкрити: Налаштування → Загальні → Гарячі клавіші](settings/general.hotkeys)
