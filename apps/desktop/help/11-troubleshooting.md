# Якщо щось не так

- **Значок у треї сірий** — ядро Banshee перезапускається після збою, зазвичай до секунди. Після трьох збоїв за хвилину — пункт «Перезапустити core» в меню трею.
- **«Базовий режим»** — причина в підказці значка й на «Огляді»: ключ, ліміт, зв'язок чи оплата.
- **Гаряча клавіша не працює** — її зайняла інша програма: зміни поєднання в налаштуваннях.
- **Не чує голос** — чи ввімкнено «Голосові команди» й чи не на паузі мікрофон (меню трею); у Windows: Параметри → Конфіденційність → Мікрофон → доступ для класичних програм.
- **Голос не запускається** — Налаштування → Голос: чи завантажено моделі голосу.
- **Інше** — «Зібрати діагностику» в «Про програму»: ZIP з журналами роботи без пам'яті й ключів.
